# 英語・日本語対応

ゲーム全体の会話・アイテム名・モンスター名・クエスト・ヘルプの日本語化には、JNetHackの翻訳と日本語文法処理を利用する。表示時の置換だけでは、アイテム名の活用、願い事、文章の引数順の変更を正しく扱えないため、英語・日本語のゲーム本体を分ける。

`DarkDungeon.exe`は言語を選択して起動するQtランチャー。`en/DarkDungeon-en.exe`、`ja/DarkDungeon-ja.exe`がそれぞれのゲーム本体。アプリ内の「Language / 言語」で選んだ言語は次回起動時の既定値となる。進行中のゲーム本体の言語は切り替わらない。

英語のセーブは既存の `%LOCALAPPDATA%\DarkDungeon` を維持する。日本語のセーブはその下の `ja` に保存する。言語間で同じセーブを読み込むことはしない。ゲーム内のキー、コマンド識別子、選択肢の返却値は各エンジンの規則を維持する。

## ソースとライセンス

- 英語・日本語双方の基礎は指定NetHackの5.0.1開発版、コミット `cb453720b1cdff0134f0872d8706fb20a764b0de`。
- 日本語参照元は https://github.com/jnethack/jnethack-release のコミット `25adee135c4bbd43ac8567664f600b565332435c`。実際に取得したソースのNetHack基礎版は5.0.0。Web上の古い3.6.7の説明を基礎版判定には使用していない。
- NetHack 5.0.0リリース `16ff59115315917b93185d026aeefea06db9b0f4` から参照元の日本語化差分を取得し、現在の5.0.1へ移植した差分を `patches/nethack-5.0.1-ja.patch` として保持する。
- 5.0.1との競合では地形効果、樹木の状態、投擲武器のひも、表示オプション等の新しい処理を維持し、文章を翻訳した。追加されたTouristクエストの文章も翻訳した。
- JNetHackの著作権表示とNetHack General Public Licenseを維持する。参照元の `dat/license` はNetHack General Public License。日本語化の著作者名は参照元のソースヘッダーに保持されている。DarkDungeonへの移植変更日: 2026-10-08。

Qtとの文章・メニュー・入力・メッセージ履歴の受け渡しは日本語本体でUTF-8とし、内部文字コードも `IC_UTF8=Y` でビルドする。Qtの標準ダイアログ用には `qtbase_ja.qm` を同梱する。Qtウィンドウポートの固定ラベルは `translations/ui-ja.json`、DarkDungeon が追加したメニューとダイアログは `src/qt_darkdungeon.cpp` に英日対応を保持する。翻訳による選択文字の変更を避けるため、ゲームのコマンド値をラベルから生成しない。

コピーとパッチ適用は `build` 内で行い、入力リポジトリを変更しない。日本語ビルドは指定コミットとの一致を検査する。

参照版に残っていた英語のメッセージ・設定説明は `translations/core-ja.json`、行動メニューは `translations/actions-ja.json`、オプションとWindowsのヘルプは `translations/help-ja.json` に補足訳を保持し、パッチに反映している。Cの書式付き文章では引数の数・型・順序を維持する。設定ファイルに書き出す `scores` の `around` 等はパーサーが読む識別子として維持する。

「ヘルプ → 遊び方」は両言語で利用できる。日本語版の `Guidebook.txt` は現在のDarkDungeonの日本語ガイド。元のNetHackの詳細説明書は `Guidebook-original-en.txt` として原文を保持する。ライセンス本文や設定・コマンドの識別子も原文を維持する。

## 検証

各言語でLua131ファイルの構文と全職業のクエスト表を検査する。データ中の敵・品物IDは、起動した各ゲーム本体の名前表に照合する。Qtの入力で移動・日本語入力・持ち物とヘルプの表示を確認し、保存後に同じ実行環境を再起動して、位置・体力・名前付き武器・メッセージ履歴の復元を確認する。テストは通常の保存先と設定を使わない。

設定名・別名229件が元の英語版と一致することと、補足翻訳の書式指定を検査する。日本語名をWindowsの保存ファイル名へ変換するときはUTF-8の各バイトを符号なしとして符号化する。保存一覧から選択した名前は、末尾の職業・種族・性別・属性を解析して再開する。「遊び方」は読んでいるキーを冒険の入力に渡さない。Claude Codeのレビューでは、設定の別名、Luaクエスト、文字列の扱い、Qtのメニュー処理を指摘され修正した。

Windowsの保存名・ロック名の領域には、名前の各バイトを `%XX` に符号化する最大長を確保する。名前入力で指定した名前の長さを維持し、復元した名前のハイフンも職業の指定として再解釈しない。日本語版の汎用文字列領域は512バイトとし、200バイトの品物接頭辞領域に加えて品物名と装備説明を収める。日本語の名前付き武器に文字化けがないことも検査する。

2026-10-08のWindows Qt検証では、通常の名前入力経路で日本語名と英語名の保存・再開を確認した。

これは自動操作での検証であり、全職業の長時間プレイや全分岐の文章表示を実地に確認したものではない。Claude Codeのレビューはソースの読み取りであり、実行結果はローカルテストの記録で確認する。
