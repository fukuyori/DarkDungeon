# 0-2 比較メニューの通常GUI確認

2026-10-28。#134のうち、専用プロフィールでのメニュー操作を確認した。アプリコードは変更せず、確認版`artifacts/phase0-comparison-geometry-v4-20261028`を使用した。

## 条件と確認結果

確認したのは非最大化・クライアント1400×900・Qt DPR 1の1条件。OS拡大率は未測定である。

`start-manual-play.ps1`で新しいプロフィール`artifacts/p0-r7-ui-20261028`を作り、英日を順番に起動した。SMOKE・固定シード・時計制御を使わず、画面操作にはcomputer-useのWindows APIを使用した。英語と日本語は別の新規ゲームであり、同じ公開場面の比較ではない。

| 操作 | 確認結果 |
|---|---|
| 英日それぞれG36/G48を選択し保存 | 4件成功。内側864×432とPNG寸法・ハッシュ・分類を検査器で照合 |
| 英語版でRestore flexible layout | 固定幅が解除され、通常の幅へ戻った |
| 日本語版でG48から通常の「拡大」 | 固定が解除され、拡大表示へ変化した |
| 日本語版で固定解除後に寸法記録を保存 | G36/G48の再設定を求める日本語メッセージを表示。追加の記録は作られなかった |
| 保存終了 | 英日ともShift+S、y、MoreでSpaceを入力し正常終了。終了後にゲームプロセスとmanual.lockは残っていなかった |

4件の記録はいずれもクライアント1400×900、内側864×432、Qt DPR 1だった。OS拡大率とは区別する。比較操作中、画面上の歩数/Timeは1のままだった。これは画面で確認した値だけで、CORE/DISP RNGや全状態の不変性の証明ではない。英語版の終了後設定は48×48、日本語版は通常拡大を行ったため64×64だった。起動前後の通常ユーザーデータ全体のハッシュ比較は今回は行っていない。
