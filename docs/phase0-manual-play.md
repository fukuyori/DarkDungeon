# フェーズ0: 通常手動確認用プロフィール（0-1）

この起動経路は、表示改修の各確認版を通常の操作で遊び、保存・終了・再開するために使う。固定シード・時計制御・SMOKE自動操作は使わない。フェーズ0全体の基準版完成や、R6の状態不変の検証が完了したという意味ではない。

## 起動

Windowsの確認用ビルドで、PowerShell 7から実行する。

```powershell
.\scripts\start-manual-play.ps1 `
  -BuildRoot .\artifacts\phase0-manual-v2-20261028 `
  -ProfileRoot .\artifacts\manual-play `
  -Language ja
```

英語は `-Language en`。再開は同じビルド・プロフィール・言語で同じコマンドを使う。新しいプロフィールは空のディレクトリか未作成の場所を指定する。既存の非空ディレクトリは、専用の識別ファイルがある場合だけ使用する。通常の利用者セーブをコピーしたり、旧セーブを移行したりしない。

必要なら `-GameArguments @('-u','PhaseZero')` のように通常のNetHack引数を渡せる。職業等の引数の名称は言語版に合わせるか、通常の人物選択画面で選ぶ。保存はゲームのメニューまたはShift+Sで行い、確認と「--More--」に応答して終了する。確認中のゲームをこのスクリプトが時間切れで終了させることはない。

ENで `-u PhaseZero -p Knight -r human -g male -a lawful` の指定と人物選択の初期値が異なる問題を観測している（tque #118）。この指定による人物の固定は確認済みとは扱わず、当面は人物選択画面で確認して開始する。

`-ProbeOnly` はランチャー・ゲーム本体の機能照会だけを実行する。ゲームの起動、プロフィールの作成、パスの実利用検証は行わない。

ランチャーを直接使う場合:

```powershell
.\artifacts\phase0-manual-v2-20261028\DarkDungeon.exe `
  --manual-profile D:/home/source/games/DarkDungeon/artifacts/manual-play `
  --language ja
```

`--language` は専用起動では必須。ゲーム本体にも `--manual-profile PATH` を直接渡せる。独立した `--capabilities` はQtアプリケーション・コア・設定の初期化前にJSONを返す。起動スクリプトとランチャーは、先に実行ファイル横の `.capabilities.json` と本体SHAを照合する。配置情報がない旧版やSHA不一致なら、照会も起動もせず拒否する。対応する本体には機能を照会し、その後に起動する。

専用モードではランチャーがゲーム本体の終了まで待機し、拒否理由を取得する。スクリプトは実効prefix・Qt設定ファイル・実行ファイルSHA・実プロセスパス・実効環境を照合してから、ランチャーPIDとゲームPIDを分けて返す。起動確認の時間切れでも両プロセスを終了させない。

## 保存領域と制限

プロフィール内は次の構成にする。

| 場所 | 用途 |
| --- | --- |
| `manual-profile.json` | 専用プロフィールの形式識別 |
| `manual.lock` | 実ゲームが保持する排他ロック。プレイ中に時間経過だけで解除しない |
| `en/data`、`ja/data` | 各言語の保存・階層・bones・記録・ロック・設定原本・診断ログ |
| `en/settings`、`ja/settings` | 各言語のQt設定。システム設定の検索先もここへ分離 |
| `en/sessions`、`ja/sessions` | 実ゲームPID、実行ファイルSHA、日時、実効prefix・Qt設定先・環境変数の有無の記録（変数の値は出力しない） |

読み取り用のDATAPREFIXだけをゲーム本体のディレクトリへ向け、他のprefixは専用dataへ固定する。同じプロフィールを同時に起動しない。言語を同時に比較する必要がある場合は、別のProfileRootを使う。

現行コアのWindowsファイルAPIの制約により、プロフィールには120文字以内のASCIIの絶対ローカルパスを使う。Unicode・UNC・長いパスは診断して拒否する。Unicodeパス対応済みとは扱わない。ジャンクション・シンボリックリンク・複数のハードリンクを持つファイルがあるプロフィール、通常保存先やゲーム配置先と重なる場所も拒否する。実行中に他のプログラムからプロフィールの内容やリンクを入れ替える使い方は対象外。

継承された `DARKDUNGEON_SMOKE_*` が1つでもあれば拒否する。環境変数を消してから起動し、専用プロフィールと自動確認を混在させない。未対応の本体やパスを指定しても通常保存先へ代替しない。

## 検証の範囲

0-1の検証記録は、実行ファイルの機能照会・拒否経路と、EN/JAのネイティブ画面、通常の保存・再開、利用者側の保存・Qt設定の前後照合を区別して残す。R5の完全な状態/RNG観測・再現制御、R6の旧通知経路の撤去・描画不変、R7の864×432の迷宮領域は別のフェーズ0タスクである。

2026-10-28の[0-1動作確認結果](phase0-manual-verification.md)では、50件の起動確認と、英語・日本語の通常操作による保存・再開を確認した。既知の残件と、確認していない範囲も同文書に記録する。
