## 自動確認

次の実行で50件が通過した。

```powershell
python tools/rendering-fixtures/verify-manual-startup.py `
  --build-root artifacts/phase0-manual-v2-20261028 `
  --evidence artifacts/phase0-ui-final-20261028 `
  --probe-helper artifacts/phase0-manual-verification-v2-20261028/manual-lock-probe.exe
```

`--snapshot-only` は手動操作前に一度だけ実行した。既存のsnapshotを上書きしない。起動照会、相対パス・Unicode・best-fit文字・長いパス・UNC・ADS・ハードリンク・非専用ディレクトリ・通常保存先・ゲーム配置先・重複/不足引数・SMOKE継承を検査した。配置情報の欠落とSHA不一致では、未対応の本体を機能照会せず拒否した。

手動操作後の通常保存先のファイル内容と、DarkDungeon/QtProjectのレジストリ値のハッシュは操作前と一致した。これはファイル内容・設定値の前後照合であり、システムコール監査で全読み書きを記録したものではない。
