# DarkDungeonの遊び方

## 冒険を始める

起動画面で「日本語」を選び、「開始」を押します。名前・職業・種族・性別・属性を選んで冒険を始めます。「ランダム」で組み合わせを選ぶこともできます。職業によって選べる種族や属性、初期装備が異なります。

通常の冒険ではNetHackの迷宮を探索します。主人公・敵・品物はNetHackのタイルで表示し、能力もNetHackのものです。

画面上部に装備とステータス、中央に迷宮、下部にメッセージを表示します。メッセージ欄は透過せず、横幅いっぱいに表示します。その直下のツールバーは、横幅に応じて1段・2段に切り替わります。

キャラクターと品物は背景を透過して地形に重ね、足元の床や階段が見えるようにします。壁は厚みのある濃い灰色の石積み、床は明るい灰色の石畳です。明るい部屋・暗い部屋・通路は床の明るさで区別できます。リアルタイム練習も同じ石の模様を使います。

## 移動と時間

矢印キーで上下左右へ移動します。移動先に敵がいれば攻撃します。壁や閉まった扉などを通り抜けることはできません。斜めの移動や詳しいキー割り当ては、ゲーム内ヘルプで確認してください。

通常の冒険はターン制です。行動すると敵も動きます。メニューを読む時間や、リアルタイム練習の時間は、通常の冒険を進めません。「行動」メニューから、探す・扉を開く・拾う・食べる・休むなどを選べます。階段の上で「上る」「下りる」を選ぶと階を移動します。

Spaceキーは、足元の箱・袋の中身を見る → 足元の品物を拾う → 足元の階段を上る／下りる → 隣接した閉じた扉を開ける、の順で基本動作を選びます。箱や品物が複数ある場合は選択画面、閉じた扉が複数ある場合は方向の確認が出ます。対象がなければ1ターン待ち、敵も動きます。箱の鍵・罠や、行動できない状態の制限は通常どおり適用します。長押しでは動作を繰り返しません。文字入力や選択画面では、Spaceの通常の操作を使います。リアルタイム練習ではSpaceで剣を構えます。

## 状態と持ち物

ツールバーは24ピクセルのアイコンの下に操作名を表示します。弓は「射撃」、パンは「食べる」、虫眼鏡は「探す」、砂時計は「休む」です。「拡大」「縮小」で迷宮のタイルを調整できます。初期サイズは48ピクセルです。ウィンドウのサイズを変えると、主人公の位置を中心に表示を調整します。上部と迷宮の境界線をドラッグして、表示領域を調整することもできます。

ツールバーは、全ボタンが横幅に収まるときは1段、収まらないときは2段へ自動で切り替わります。「基本動作」（Spaceと同じ動作）と、よく使う行動に続いて、「持ち物」「武器を構える」「道具を使う」「容器の中身」（足元の容器を見る）「扉を開く」「扉を閉じる」「上る」「下りる」と拡大・縮小があります。ステータス欄もウィンドウの横幅に合わせて広がり、ログと並びます。対象の品や方向の質問は通常どおり表示します。質問中に別の行動を選ぶ場合は、先に質問をキャンセルしてください。「容器の中身」でも鍵や罠の確認が適用されます。

画面上部に体力、魔力、防御値、レベル、金貨、歩数、属性などを表示します。体力が尽きると冒険を続けられません。防御値は通常、小さいほど攻撃を受けにくくなります。空腹・混乱・盲目・石化などの状態にも注意してください。

「情報」から持ち物・能力・発見済みの品・技能・迷宮の概要を確認できます。持ち物には選択文字が付きます。品物の正体が分からない間は、外見の名前を表示することがあります。品物には祝福・呪いなどがあり、名前や外見だけで安全とは判断できません。

「装備」では武器を構える、防具を着る、装飾品をつけるなどを選べます。道具は「行動」の「道具を使う」、飲み薬・巻物・魔法の杖・呪文などは「魔法」から操作します。質問が出たら、対象の品や方向を選んでください。品物への名前付けや文字入力には日本語を使えます。

## 敵・ペット・探索

敵との接触、遠距離攻撃、罠、空腹、危険な品物などが体力や状態に影響します。ペットや友好的な相手もいるので、攻撃前の質問を確認してください。店では品物の代金を支払う必要があります。見慣れない記号や生き物は「情報」の調べるコマンドで確認できます。

NetHackの通常の目的は、迷宮でイェンダーの魔除けを手に入れ、神に捧げることです。階や職業のクエストには独自の条件があります。ターン制とリアルタイムを組み合わせるルールの詳細は検討中です。

## リアルタイム練習

「練習 → リアルタイム練習」を選ぶと、現在の階の地形で操作を試せます。

| 操作 | キー |
|---|---|
| 移動 | 矢印 / WASD |
| 剣を構える | Spaceを押している間 |
| 一時停止・再開 | P |
| 練習を最初からやり直す | R |
| 冒険に戻る | Esc |

剣の構えと向き、盾、敵や飛び道具の動きを試してください。主人公と敵はNetHackのタイルで表示し、構えた剣は線で表示します。ウィンドウが非アクティブになると一時停止します。Pで再開できます。練習中の位置・体力・撃破数は通常の冒険に反映されません。閉じると練習状態は消えます。練習用の地図には未探索の場所も表示します。

## 保存・終了・言語

「ゲーム → 保存して終了」で冒険を保存します。次回起動時に保存された冒険を選んで再開します。「保存せず終了」は冒険を保存する操作ではありません。

言語は起動画面で選べます。ゲーム内の「言語」で選んだ設定は、次回の起動に適用します。進行中の冒険は保存して終了してください。英語と日本語の冒険は別々に保存するため、切り替えても同じ冒険の言語は変わりません。

## 詳しいヘルプと設定

「ヘルプ」や「情報」のメニューからコマンドや品物の説明を参照してください。メニューの検索は、表示されている文字を検索します。「ゲーム → ゲーム設定」では冒険の設定、「画面設定」では文字・タイル・装備欄などの表示を調整できます。設定名や拡張コマンド名は英語の識別子を使います。

このガイドはDarkDungeonの現在の操作を説明します。元のNetHackの詳細な説明書も参考資料として同梱しています。
